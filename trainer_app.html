Установить на телефон

iPhone (Safari):

  1. Открой этот файл в Safari
  2. Нажми кнопку «Поделиться» (квадрат со стрелкой вверх)
  3. Выбери «На экран "Домой"»
  4. Нажми «Добавить» — появится иконка как у приложения

Android (Chrome):

  1. Открой файл в Chrome
  2. Меню (три точки) → «Добавить на главный экран»

Но сначала файл должен быть доступен по URL — см. ниже.

🌐 Как получить постоянную ссылку
Самый простой способ — GitHub Pages (бесплатно):
1. Зарегистрируйся на github.com
2. Создай репозиторий → загрузи trainer_app.html
3. Settings → Pages → Source: main → Save
4. Получишь ссылку: username.github.io/repo
5. Открой на телефоне → добавь на главный экран

Или через Telegram: отправь файл себе в «Сохранённые сообщения» → скачай на телефон → открой в браузере.
